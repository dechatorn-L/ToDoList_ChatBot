# 02: Task Completion, Priority Tiers & Deletion

**What to build:**
Users can toggle tasks between completed and active (with strikethrough visual feedback), assign a priority tier (High, Medium, Low) with distinct color-coded badges, delete unwanted tasks individually, and click a "Clear Completed" button to purge all completed items. All changes update `localStorage` and are verified by tests.
